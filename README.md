# 月夜が魅せる物語 -Fated Moonlight-

クトゥルフ神話TRPGシナリオ『月夜が魅せる物語』（作:唯燐 / 文:じゃこ缶・きりぅ）を原作とする、
マルチエンディング方式のビジュアルノベル／アドベンチャー（二次創作）です。
2016年12月の東京を舞台に、失踪事件の謎解きとコズミックホラーを、日ごとの行動選択と
育成・シミュレーション要素で体験できる一人用ゲームを目指しています。

> **非公開・身内プレイ用**のプロジェクトです。一般公開・販売は行いません。
> 公開範囲を広げる場合は、原作者への許諾確認が別途必要です。

## 概要

- ジャンル：ビジュアルノベル／アドベンチャー ＋ 育成・シミュレーション
- エンジン：[Ren'Py](https://www.renpy.org/) 8.x
- 言語：日本語のみ
- 構想：原作の結末をほぼ網羅する7エンディング構成
- 現在の状態：フェーズ1（MVP）実装済み
  （12/21 居酒屋「夜叉」での依頼 〜 12/22夜「東風谷雪との遭遇イベント」、分岐なしの一本道）

## 遊び方

1. Ren'Py SDK（8.x系）をインストールする
2. Ren'Py ランチャーで `renpy/` ディレクトリをプロジェクトとして開く
3. 「実行」ボタンで起動
