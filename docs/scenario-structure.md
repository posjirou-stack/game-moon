## 1. 全体構造

```
プロローグ（性別選択）
  └─ 第1章 一本道（12/21夜 夜叉 〜 12/22夜 雪との遭遇）……実装済み
       └─ 調査パート（12/23〜12/29昼、カレンダー行動選択・全20枠）……本書の主対象
            ├─ 5本のメインチェーン（F1〜F5に対応）
            ├─ 勢力（協力組織）獲得サブシステム
            ├─ 育成コマンド（スキルライン成長）
            └─ 日付固定イベント（世界の進行・タイムリミット）
       └─ クライマックス（12/29夜 哲学堂公園 ムーンレンズ争奪戦）
            └─ 7エンディング判定（endings.rpy 実装済みの骨格に本文を執筆）
```

### ゲーム化の基本方針

1. **原作のKP裁量をチェーン化する**: 原作は自由探索だが、本作では「メインチェーン」
   （順序のあるイベント列）として翻案する。チェーンの次のイベントが行動選択画面に出現する。
2. **技能ゲート**: 原作の「情報取得難度ランク0〜4」を4方向スキルラインの閾値に変換する（§8）。
3. **1周で全回収不可**: 行動枠20に対し、全チェーン完遂に必要な行動数は約28〜32になるよう
   設計し、「今回はどの結末を狙うか」の取捨選択を強制する（周回前提）。
4. **タイムリミットの可視化**: 原作の時限イベント（東風谷家焼失・特別礼拝・凛久の洗脳完了・
   儀式）はカレンダー上の締切として明示し、HUD/行動選択画面で警告する。
