# 月夜が魅せる物語 -Fated Moonlight-（プロトタイプ）

TRPGシナリオ『月夜が魅せる物語』（作:唯燐 / 文:じゃこ缶・きりぅ）を原作とする二次創作ゲーム。
**非公開・身内プレイ用**。詳細は `../docs/requirements.md` の要件定義書を参照。

## 現在の実装範囲（フェーズ3 前半まで）

- チャプター1（12/21 居酒屋「夜叉」の依頼 〜 12/22夜「東風谷雪との遭遇イベント」、一本道）
- **カレンダー行動選択ループ**（12/23〜12/29 を「日×時間帯」の行動枠で進行するハブ&スポーク構造）
- **5本のメインチェーン本文**（`docs/scenario-structure.md` 3章の設計に基づく計27イベント）
  - YUKI: 雪の記憶回復と保護（F2）／ LENS: ムーンレンズ（F1の材料。偵察・武器工場破壊・
    防衛計画奪取=瑞名救出）／ RIKU: 凛久救出（F3・12/28 21時期限）／
    SIGN: 死へと誘う印（F4。別ルートとして12/25夜の「特別な説法」潜入=自分の印のみ解除）／
    ENDO: 遠藤啓介（F5・END⑥）
- **勢力獲得イベント6種**（久美・政府/SHIELD・参軒屋・山蓮界・銀の黄昏教団・バベッジ工作。
  クライマックスのF1精算と解呪儀式の魔術師動員数に効く）
- **「雪と過ごす」**（繰り返し可。記憶回復度・保護状況・凛久救出で本文が変化。SAN小回復+関係値）
- **朝のニュース**（日付固定イベント・締切警告・状況に応じたヒントの通知）
- **暗殺カウンタ**（敵組織の注意度が閾値を超えると襲撃イベント→敗北でEND⑦）
- **資料庫**（入手した原作ハンドアウト・文書を読み返せる。ステータス画面から）
- **クライマックス多段構成**（テロ/静穏の導入分岐→勢力の陽動→異空間突入→教団幹部との対峙→
  レンズ回収→守護者からの逃走。突入失敗時は儀式決行の描写へ）
- **7エンディング本文**（周回状況・関係値・選択で変化するエピローグ差分。
  END⑥は「引き留める(要:菫の信頼)/見送る/共に行く」の3分岐）
- **GUIテーマ**（Ren'Py標準テンプレート+月夜配色。タイトル画面・セーブ/ロード・設定・履歴・
  終了確認などフル装備。gui/button/ の背景PNGは自前生成の単色画像）
- **事件簿**（タイトル画面からエンディング回収状況を確認。未達成はヒント表示）
- **HUD**（画面右上に日付・時間帯・SANを常時表示）と**ステータス画面**（F1キーまたはHUDのボタン）
- 開発用**デバッグメニュー**（後述）

## ファイル構成の規約

| ファイル | 役割 |
|---|---|
| `game/script.rpy` | エントリポイント。キャラクター定義・背景プレースホルダー・プロローグ（性別選択） |
| `game/chapter1.rpy` | チャプター1本文（12/21〜12/22の一本道） |
| `game/calendar.rpy` | カレンダー行動選択ループ。行動枠の定義・調査イベントの登録（`EVENTS`）・行動選択画面・朝のニュース |
| `game/chapter2_yuki.rpy` ほか `_lens/_riku/_sign/_endo` | 各メインチェーンのイベント本文 |
| `game/chapter2_events.rpy` | 育成コマンドと暗殺襲撃イベント |
| `game/endings.rpy` | クライマックス（儀式）・F1/F2精算・エンディング判定・7エンディング |
| `game/status.rpy` | 変数定義と共通関数（`skill_check` / `gain_skill` / `change_san` / `set_flag` / `add_heat` など） |
| `game/archive.rpy` | 資料庫（文書データ `ARCHIVE_DOCS`・`add_archive`・資料庫画面） |
| `game/screens_status.rpy` | HUD・ステータス画面 |
| `game/casebook.rpy` | 事件簿（エンディング回収状況とヒント） |
| `game/debug.rpy` | デバッグメニュー（`config.developer` 時のみ有効） |
| `game/gui.rpy` / `game/screens.rpy` | GUIテーマ（標準テンプレート改変版。`gui.scale()`は数値展開済み） |
| `game/options.rpy` | 基本設定 |

**シナリオ執筆の基本フロー**: 調査イベントを増やすときは、該当チェーンのファイル
（なければ新設）にラベルを書き、`calendar.rpy` の `EVENTS` リストに
`InvestigationEvent` を1件追加する。設計は `docs/scenario-structure.md` を正とする。

**既知の制約**: 行動選択画面・資料庫のリスト操作はマウス推奨
（キーボードフォーカスがviewport内のボタンに入らない場合がある）。

## 遊び方

1. [Ren'Py](https://www.renpy.org/) SDK（8.x系）をインストールする
2. Ren'Pyランチャーで、このディレクトリ（`renpy/`）をプロジェクトとして開く
3. 「実行」ボタンで起動

コマンドラインから直接起動する場合（Ren'Py SDK同梱の `renpy.py` を利用）：

```sh
python3 /path/to/renpy-sdk/renpy.py /path/to/game-moon/renpy run
```

構文チェック（コミット前に推奨）：

```sh
python3 /path/to/renpy-sdk/renpy.py /path/to/game-moon/renpy lint
```

## デバッグメニュー（開発用）

SDKから直接起動した場合（`config.developer` が有効な環境）のみ、
**F2キー**またはHUD右上の「デバッグ」ボタンから開ける。配布ビルドでは自動的に無効になる。

- 任意のシーン・7エンディングへの直接ジャンプ
- スキル・SANの増減、分岐フラグ（F1〜F5・特殊ルート）のON/OFF
- カレンダーの時間送り

ステータス画面（F1）も、開発環境では分岐フラグの内部状態を追加表示する。

## フォントについて

日本語表示のため IPAゴシック（`game/fonts/ipag.ttf`）を同梱しています。
IPAフォントライセンスv1.0のもとで再配布可能なフォントです。
