# 背景画像の置き場所

ここに背景画像を置くと、次回起動時から自動で反映されます（無い間は単色プレースホルダーで動作）。
拡張子は png / jpg / jpeg / webp のいずれでも可（png が最優先）。サイズは 1280x720 推奨。

## 現在の投入予定（生成済みぶん）

| ファイル名 | 用途 |
|---|---|
| `alley.png` | 裏路地（雪と遭遇） |
| `street_night.png` | 夜の繁華街（新橋） |
| `izakaya.png` | 居酒屋「夜叉」 |
| `title.png` | タイトル画面 |
| `campus.png` | 光山大学 |
